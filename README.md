# WeDo Market — вёрстка личного кабинета (десктоп + мобильная версия)

Статическая вёрстка на HTML + CSS + JS по макету Figma `wedomarket` (страница «reверстка»): десктопные экраны 1920px и мобильные 375px. Одна страница = один URL: на ширине ≥768px показывается десктопный каркас (шапка, сайдбар, футер), на ≤767px — мобильный (шапка с логотипом и колокольчиком, нижняя навигация с меню «ещё», мобильный футер).

## Структура

```
css/base.css     — токены (цвета, тени, радиусы), шрифты, сброс, кнопки, поля форм, радио, бейджи
css/layout.css   — контейнер, шапка, сайдбар, футер, сетка «сайдбар + контент», адаптив
css/pages.css    — стили конкретных страниц (дашборд, задание, мастер создания)
css/mobile.css   — мобильный каркас: шапка, нижняя навигация + меню, блок «Прогресс создания», футер, табы
css/tasks-mobile.css, chats.css, notifications.css, performers.css — мобильные стили разделов
js/tasks-mobile.js, chats.js, notifications.js, performers.js — интерактив разделов (панель «Совет ИИ», вложения чата, тумблеры, вкладки)
js/main.js       — меню пользователя, аккордеон «Задания», график, дропзона видео, кнопки «Сегодня/Завтра»
assets/icons/    — SVG-иконки из Figma
assets/img/      — логотип, платёжные системы, карта
fonts/           — сюда положить файлы шрифта Gilroy (см. fonts/README.md)
_build/          — генератор страниц: common.py (шапка/футер/сайдбар/мобильный каркас), pages_*.py (страницы по разделам), build.py. Необязателен: можно править HTML напрямую
```

## Как открыть

Просто открыть любой `.html` в браузере (двойным кликом, без сервера). SVG-иконки при сборке встраиваются прямо в HTML и красятся через CSS `color`. Если нужен локальный сервер:

```
python -m http.server 8000
```

и откройте `http://localhost:8000/`.

## Пересборка страниц через генератор

Шапка, футер и сайдбар описаны один раз в `_build/build.py`. После правки запустите:

```
python _build/build.py
```

— все страницы перезапишутся.

## Заметки

- Ширина контейнера 1320px, как в макете. Брейкпоинты: ≥1200 — десктоп как в макете; 768–1199 — планшет (сайдбар/колонки перестраиваются); ≤767 — мобильная версия по макету 375px.
- В HTML мобильные и десктопные фрагменты помечены классами `.m-only` / `.d-only` там, где структура экрана отличается.
- Нижняя мобильная навигация: кнопка «⋯» открывает меню (О компании … Тех поддержка); на шагах создания задания над навигацией показывается блок «Прогресс создания».
- График «Завершенные задания» рисуется SVG в `js/main.js`; данные задаются в атрибуте `data-chart="[...]"` (12 значений по месяцам).
- Карта на странице задания — статичная картинка из макета (`assets/img/map.webp`); при интеграции заменить на виджет карт.
- Капча — визуальная заглушка под Yandex SmartCaptcha.
