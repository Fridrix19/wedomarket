# Шрифт Gilroy

В макете используется коммерческий шрифт **Gilroy** (начертания Light 300, Regular 400, Medium 500, SemiBold 600, Bold 700), поэтому файлы в репозиторий не включены.

Положите сюда файлы с такими именами (подключены в `css/base.css`):

```
Gilroy-Light.woff2     Gilroy-Light.woff
Gilroy-Regular.woff2   Gilroy-Regular.woff
Gilroy-Medium.woff2    Gilroy-Medium.woff
Gilroy-SemiBold.woff2  Gilroy-SemiBold.woff
Gilroy-Bold.woff2      Gilroy-Bold.woff
```

Пока шрифта нет, используется системный запасной (`Manrope` / `Segoe UI` / system-ui) — метрики отличаются, поэтому переносы строк могут не совпадать с макетом.

Для поля времени («00:00») в макете использован **Ubuntu Medium** — подключите его при необходимости, иначе применится основной шрифт.
